# 🌍 WonderLust – Modern Travel Website

WonderLust is a modern, responsive, and interactive travel website built using **HTML5**, **CSS3**, and **JavaScript**. It provides users with an engaging travel experience by allowing them to explore destinations, search places, view destination details, switch between light and dark modes, and simulate trip bookings through an interactive booking form.

🔗 **Website:** https://wonderlust-travels-web.netlify.app/

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Sumanth30-git/wonderlustweb.git
```

Move into the project folder

```bash
cd wonderlustweb
```

Open the project using **Visual Studio Code**.

Install the **Live Server** extension.

Right-click on **index.html** and select:

```
Open with Live Server
```

# 💡 Key Functionalities

### 🔍 Search Destinations

Users can instantly search destinations by typing into the search box.

---

### ❤️ Favorite Button

Users can mark destinations as favorites by clicking the heart icon.

---

### 📋 View Details

Displays:

- Destination Name
- Price
- Duration
- Rating
- Destination Image

inside an interactive popup.

---

### 🛫 Booking Form

Users can book their trip by providing:

- Full Name
- Email
- Phone Number
- Travel Date
- Number of Travelers

---

### 🌙 Dark Mode

Supports both:

- Light Theme
- Dark Theme

for a better user experience.

---

### 📱 Responsive Design

Optimized for:

- Desktop
- Laptop
- Tablet
- Mobile Devices
